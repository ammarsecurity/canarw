# CANARW — قالب ووردبريس

قالب مخصص لشبكة العمل المناخي للعالم العربي، مع لوحة إدارة عربية ومحرر أقسام بصري. الإصدار 1.1.0 يدعم اتجاه القالب بالكامل حسب لغة الصفحة: RTL للعربية وLTR للإنجليزية. يتضمن المحتوى العام المرئي الملتقط من `https://www.canarw.org/` بتاريخ 4 أكتوبر 2026: 16 صفحة و91 صورة.

## تحديث النسخة الموجودة

من **المظهر ← قوالب ← أضف قالباً جديداً ← رفع قالب** ارفع ZIP الجديد، ثم اختر **استبدال القالب الحالي بالقالب المرفوع**. تبقى الصفحات والصور والتعديلات المحفوظة في قاعدة بيانات ووردبريس. لا تحتاج إعادة استيراد البيانات عند التحديث. امسح كاش الموقع والمتصفح إذا ظلت أدوات أو أنماط النسخة القديمة ظاهرة.

## التثبيت

1. ادخل إلى لوحة ووردبريس، ثم **المظهر ← قوالب ← أضف قالباً جديداً ← رفع قالب**.
2. ارفع ملف `canarw-wordpress-theme-v1.1.0.zip` نفسه، ثم اضغط **التنصيب الآن** و**تفعيل**.
3. افتح **CANARW ← البيانات الافتراضية**، ثم **استيراد / استئناف البيانات**. اترك الصفحة مفتوحة إلى أن يظهر اكتمال الاستيراد.
4. افتح **الإعدادات ← الروابط الدائمة**، واختر **اسم المقالة** إذا أردت الروابط النصية المطابقة لمسارات الموقع الأصلي، ثم احفظ.
5. افتح **CANARW ← الصفحات والمحتوى** لتعديل المحتوى، و**هوية الموقع** لتعديل الشعار والألوان والبريد والعنوان.

لا يحتاج القالب إلى Elementor أو ACF أو إضافات مدفوعة. الصور مرفقة ويستوردها القالب محلياً إلى مكتبة الوسائط؛ لا يحتاج استيراد البيانات إلى الاتصال بالموقع الأصلي.

## تعديل النصوص والصور

من **CANARW ← الصفحات والمحتوى ← تعديل المحتوى**:

- عدّل عنوان الصفحة ووصفها ولغتها وحالتها.
- لكل قسم: عدّل العنوان والنص التمهيدي، وحدّد تصميمه وخلفيته.
- لكل عنصر: عدّل النص أو اختر صورة من مكتبة الوسائط، أو غيّر الرابط.
- استخدم ↑ و↓ لترتيب الأقسام والعناصر. يمكن نسخها أو حذفها أو إخفاء قسم كامل.
- أضف قسماً جديداً من أسفل الصفحة، ثم أضف عناصره.
- اضغط **حفظ التغييرات**، ثم **معاينة** لرؤية النتيجة الفعلية.
- **استعادة نسخة المحتوى السابقة** تستعيد الأقسام والنصوص والصور من الحفظ السابق. لا تعيد عنوان الصفحة أو رابطها أو حالة النشر.

المحرر يفتح تلقائياً على تبويب **مرئي**؛ اكتب مباشرة، وحدّد النص لتطبيق التنسيق. يحتوي على:

- عريض، مائل، تسطير وشطب؛ عناوين وفقرات واقتباسات وقوائم نقطية ومرقمة.
- محاذاة، مسافات بادئة، نوع الخط وحجمه، لون النص ولون التمييز.
- إدراج وتعديل الروابط، الصور والمعارض وملفات الصوت والفيديو عبر **إضافة وسائط**.
- إدراج الجداول وإضافة أو حذف صفوفها وأعمدتها. الجداول ذات الخلايا المدمجة تُعدّل من HTML للحفاظ على بنيتها.
- البحث والاستبدال، التراجع والإعادة، الرموز الخاصة، خطوط الفصل، إزالة التنسيق واللصق كنص.
- ملء الشاشة، دليل المساعدة، عداد الكلمات وتبويب HTML الاختياري.
- **Ctrl / ⌘ + S** لحفظ الصفحة، و**Ctrl / ⌘ + Z** للتراجع.

لغة الصفحة تغيّر اتجاه الكتابة داخل المحرر فوراً، وتغيّر الهيدر والقوائم والأقسام والفوتر في الموقع بعد الحفظ. تستطيع تغيير اتجاه فقرة معينة من أدوات RTL/LTR للنص المختلط. بيانات الهاتف والبريد تبقى معزولة نصياً للحفاظ على ترتيبها الصحيح.

إذا كانت ميزة التحرير المرئي معطّلة في ملف المستخدم الشخصي، فعّلها لتظهر أدوات المحرر المرئي. تبويب HTML يظل متاحاً.

الصفحات المستوردة تستخدم محرر أقسام CANARW. تظهر في قائمة صفحات ووردبريس المعتادة أيضاً، مع رابط إلى محرر الأقسام. يحتفظ القالب بنسخة من محتوى الأقسام داخل `post_content` لتصديرها والاحتفاظ بالمحتوى عند تبديل القالب؛ تعديل هذه النسخة من المحرر العادي لا يغيّر الأقسام المعروضة.

## الفوتر والقوائم

- **CANARW ← الفوتر والروابط**: حقوق النشر، مجموعات روابط المصادر، الروابط الاجتماعية وشعارات الشركاء.
- **المظهر ← قوائم**: القوائم العربية والإنجليزية وقائمة الفوتر الاختيارية.
- أسماء روابط الموقع الأصلي والنصوص التجريبية الموجودة فيه محفوظة ضمن البيانات الافتراضية ويمكن تعديلها.
- زر اللغة ينقل بين الصفحات العربية والإنجليزية المتقابلة، أو إلى الصفحة الرئيسية للغة إذا لم تكن هناك صفحة مقابلة.

## رسائل التواصل

تُحفظ رسائل نموذج التواصل في **CANARW ← رسائل التواصل**. إرسال إشعار إلى البريد اختياري من **هوية الموقع**، ويحتاج إعداد إرسال البريد في الاستضافة. تأكيد إرسال النموذج يعني حفظ الرسالة في ووردبريس، وليس ضمان وصول إشعار البريد.

مدة الاحتفاظ بالرسائل الافتراضية 90 يوماً، ويمكن ضبطها من 7 إلى 365 يوماً. يستخدم الحذف التلقائي جدولة ووردبريس؛ عند تعطيل WP-Cron يجب تشغيله من الاستضافة. استثنِ صفحات نموذج التواصل من تخزين الصفحة الكامل في إضافات الكاش لتبقى رموز تحقق النموذج محدثة.

## سلوك الاستيراد

ينشئ الاستيراد الصور والصفحات والقوائم. يعمل على دفعات ويمكن استئنافه بعد انقطاع الاتصال. تشغيله مرة أخرى لا يكرر الصور المستوردة أو يستبدل الصفحات الموجودة والتعديلات المحفوظة. الصفحات المحذوفة إلى سلة المهملات تُعامل كمفقودة ويُنشأ لها بديل.

عند تحديد خيار تعيين الصفحة الرئيسية، يربط الاستيراد الصفحة الرئيسية والقوائم المستوردة. يظل هذا الخيار متاحاً عند تكرار الاستيراد. إذا كانت إعدادات الهوية محفوظة مسبقاً، يحتفظ بها بدلاً من استبدالها بالهوية الافتراضية.

## الصفحات المرفقة

الرئيسية العربية، الأعضاء، العمل المناخي، التواصل، COP30/31، المبادرات، الأنشطة، أهداف التنمية المستدامة، هيكل الشبكة، التقارير والموارد، العدالة المناخية؛ والصفحات الإنجليزية الرئيسية، من نحن، المبادرات، الأعضاء وStore.

صفحة العدالة المناخية كانت فارغة في المرجع، لذا أُرفقت فارغة وجاهزة للتعديل. بعض صفحات المرجع تحتوي نصوصاً تجريبية وصوراً توضيحية، وأُبقيت كما هي. صفحة Store تتضمن محتواها المرئي الملتقط فقط؛ القالب لا يضيف منتجات ديناميكية أو سلة تسوق أو بوابة دفع. المظهر أعيد تنظيمه في تصميم متجاوب، وليس نسخة مطابقة لكل بكسل من موقع Hostinger الأصلي.

## المتطلبات والملفات

- ووردبريس 6.5 أو أحدث.
- PHP 7.4 أو أحدث؛ يوصى بـPHP 8.3 أو أحدث.
- مكتبة GD أو Imagick لإنشاء مقاسات الصور، ومجلد uploads قابل للكتابة.
- حجم ملف ZIP يقارب 37 ميغابايت. إذا كان حد الرفع في الاستضافة أقل، ارفع مجلد `canarw` بعد فك الضغط إلى `wp-content/themes/` باستخدام مدير الملفات أو FTP.
- الخط العربي مرفق محلياً. لا توجد مكتبات JavaScript أو خطوط خارجية مطلوبة للعرض.

راجع `docs/installation-ar.html` للدليل المصوّر و`docs/source-inventory.json` لجرد الصفحات والصور المأخوذة من المرجع.
